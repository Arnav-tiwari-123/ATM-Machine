
# 🏧 ATM Machine in Python

A simple ATM Machine project built using Python. This program allows users to check their balance, deposit money, withdraw money, and exit the system after entering the correct PIN.

## 📌 Features

- PIN Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Menu Driven Program
- Uses While Loop for Multiple Transactions

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open terminal or command prompt.
4. Run the file:

```bash
python atm.py
```

## 🔑 Default Credentials

| PIN | Balance |
|------|---------|
| 1234 | ₹10,000 |

## 📋 Menu Options

1. Check Balance
2. Deposit Money
3. Withdraw Money
